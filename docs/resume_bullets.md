# Resume Bullets

- Built Aegis Localization, a C++ ROS2 state-estimation framework comparing EKF, UKF, and particle-filter localization using noisy odometry/IMU fusion, synthetic benchmarking, and trajectory-error evaluation.
- Implemented modular ROS2 filter nodes, shared C++ estimation libraries, and reproducible benchmark tooling for multi-scenario ATE, drift, yaw-error, and update-rate analysis.
- Integrated a headless TurtleBot3 Gazebo validation launch that spawns the robot, drives a repeatable command profile, and runs all three estimators against simulated odometry and IMU topics.
